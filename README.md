1.项目名称
Engine Health Analysis
航空发动机健康状态分析和剩余寿命预测(RUL)

2.项目简历
基于C-MAPSS航空发动机数据集RUL_FD001.txt，完成对发动机传感器的数据分析，特征工程，使用机器学习模型预测剩余寿命
实现
单个/多个传感器可视化
RUL预测(RandomForest)
预测值和真实值的差异
特征重要性

3.环境依赖
pandas 数据分析
matplotlib 可视化绘图
scikit‑learn 机器学习模型

4.安装方法
git clone https://github.com/zhangshuhan546‑glitch/Engine-Health-Analysis
cd Engine-Health-Analysis
pip install -r requirements.txt
python analysis.py
python predict.py
